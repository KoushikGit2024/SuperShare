Checking SuperShare service
Phone cannot connect?
  1. Keep the SuperShare terminal open. It must be listening on TCP port 8765.
  2. Match the address to the hotspot host. If the phone provides the hotspot, connect the laptop to it and use the laptop’s Wi-Fi IPv4 address. If this laptop provides Windows Mobile Hotspot, connect the phone to it and use the Windows hotspot address, usually 192.168.137.1.
  3. Open the exact address shown above, including :8765. The phone must not use localhost.
  4. Approve the Windows setup prompt when SuperShare starts. It sets the network profile to Private and adds a TCP rule scoped to local-subnet addresses.

Do not configure router port forwarding. If both devices are on the same hotspot and the page still times out, check hotspot client isolation. Changing HTTP to HTTPS does not fix a TCP timeout; HTTPS also requires trusting SuperShare’s local certificate on the phone.
